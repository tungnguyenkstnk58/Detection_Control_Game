# resilience-induced-blindness

Python simulation code for the paper:

**Detection–Control Games under Hidden Modes: Resilience-Induced Blindness Phenomenon**

The code reproduces the numerical studies on the interaction between hidden-mode detection and belief-dependent control, including:

- relative state cost under fixed and switching modes;
- different detector sensitivities and switching periods;
- detection-delay analysis;
- paired Monte Carlo simulations under Gaussian disturbances.

## Requirements

- Python 3
- NumPy
- SciPy
- pandas
- Matplotlib

The simulation can be run directly in Google Colab or Jupyter Notebook.

## How to Run

1. Open the simulation notebook.
2. Select the desired run mode and simulation parameters.
3. Run all cells sequentially.
4. The generated figures and CSV files will be saved in the output folder.
